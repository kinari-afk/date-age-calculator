⏳ ChronoCalc (クロノカルク) - 暦と年齢の計算ダッシュボード
「あれ、今年で何歳だっけ？」「四十九日はいつ？」「履歴書の入学年は…？」
そんな日常のちょっとした「時間」や「暦」の疑問を、ワンタップで解決する直感的な計算ダッシュボードです。
Appleのようなミニマルさ、Notionのような情報整理、Airbnbのような親しみやすさを目指し、**「ただ数字が出るだけじゃない、触っていて心地よいUI」**にこだわって作りました。
✨ 主な機能
機能は大きく3つのタブに分かれており、目的の計算にすぐアクセスできます。
📅 1. 日付・年齢計算 (Basic Calculator)
基準日（今日や生年月日など）を設定するだけで、あらゆる情報が連動して表示されます。
年・年齢計算: 「5年前は何年？」「50歳になるのは西暦・和暦でいつ？」
逆引き計算: 「2030年は自分にとって何歳の年？」
日数計算: 「今日から100日後はいつ？」
⏱ 2. 期間の詳細計算 (Duration Details)
2つの日付（開始日と終了日）を指定して、その間の正確な期間を算出します。
暦通りの期間: 「1年3ヶ月15日」など、カレンダーに沿った正確な表示
柔軟なオプション: 「開始日と終了日を両方含む（＋1日）」の切り替えもワンタップ
各種換算: 期間を「週・月・年」や「時間・分・秒」でざっくり把握できます
📜 3. 自動年表作成 (Auto Timeline)
一番面倒なリスト作成を自動化！基準日を入力してボタンを押すだけで、一覧表がポップアップで生成されます。
🎓 入学・卒業年表: 履歴書作成の強い味方。早生まれ（1/1〜4/1）も自動で判定して学歴表を作成。
🎉 長寿のお祝い年表: 還暦（60歳）から百寿（100歳）まで、それぞれの由来とともに一覧表示。
📿 法要・年忌表: 命日を入力するだけで、初七日から五十回忌までのスケジュールが瞬時に分かります。
💡 こんな時に便利！
就活・転職活動: 履歴書の学歴欄を埋めるとき
家族のイベント: 親の還暦祝いや、子どもの100日祝いを計画するとき
法事の準備: 四十九日や一周忌などの日程を親戚に伝えるとき
記念日の確認: カップルや夫婦の「付き合って1000日」を計算するとき
📱 こだわりの操作性
西暦 / 和暦 のシームレスな切り替え: どちらからでも入力でき、自動で相互変換されます（干支も表示！）。
スマホ完全対応: 狭い画面でもキーボード入力なしで操作できる「＋/−」ボタンを搭載。
インストール不要: ブラウザですぐに動くので、いつでもどこでもパッと使えます。
